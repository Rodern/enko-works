Combined flowchart example: Library fine checker

Scenario: process each borrowed book, decide if overdue, and call a sub-routine to compute fine.

Construct map

  • Sequence: input, initialize counter, output.
  • Selection: daysLate > 0 decides whether to fine.
  • Iteration: repeat for each book.
  • Sub-routine: CalculateFine handles reusable fine logic.

Practice prompts

  1. Add another selection: if daysLate > 30 then output "manager review".
  2. Suggest one extra sub-routine to keep the main algorithm simpler.
  3. Explain why this design is easier to test than one long block.
Answer guide: adding layered decisions supports policy rules; extra sub-routines like FormatMessage improve readability; modular sections are easier to test and debug independently.
