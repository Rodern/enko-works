Form 3 Objective Page: 9CT.04 Sub-routines

Sub-routines are reusable mini-algorithms inside a bigger algorithm. Even when not written as code, students should understand call, run, and return.

Cambridge Form 3 Algorithm Design Decomposition
Back to main Form 3 page

Success criteria: you can explain why a sub-routine improves readability, reduces repetition, and makes updates easier.

Core understanding

Key language: sub-routine, procedure, call, return, modular design.

Example pseudocode

MAIN
  INPUT name
  CALL FormatGreeting(name)
  OUTPUT message
END MAIN

SUB-ROUTINE FormatGreeting(personName)
  message <- "Welcome " + personName
END SUB-ROUTINE

Visual flowchart: Call and return

Python translation of sub-routines

Pseudocode to Python

def format_greeting(person_name):
    message = "Welcome " + person_name
    return message

name = input("Name: ")
message = format_greeting(name)
print(message)
