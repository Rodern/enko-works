Exercise 1: HTML Structure

  1. Create a page with ``, `html`, `head`, `title`, and `body`.
  2. Add one `h1`, one `h2`, and two `p` elements.
  3. Add `header`, `main`, and `footer` elements.

Exercise 2: Lists and Links

  1. Add one ordered list with 5 items.
  2. Add one unordered list with 5 items.
  3. Add two links: one external and one internal anchor link.

Exercise 3: Images and Navigation

  1. Insert one image with correct `alt` text.
  2. Create a navigation bar with at least 4 links.
  3. Make links jump to sections in the same page.

Exercise 4: Tables

  1. Create a table with `thead` and `tbody`.
  2. Add 5 rows of data and at least 4 columns.
  3. Use `th` for headings and `td` for data.

Exercise 5: Forms

  1. Create a form with name, email, age, class, and message fields.
  2. Use input types: `text`, `email`, `number`, and `radio` or `checkbox`.
  3. Add `label` elements and `required` where needed.

Exercise 6: CSS Basics

  1. Style body, headings, paragraphs, and links.
  2. Use classes to style cards and buttons.
  3. Add hover styles for links and buttons.

Exercise 7: Layout and Responsive Design

  1. Create a two-column layout using Grid or Flexbox.
  2. Add a media query to switch to one column on small screens.
  3. Ensure images scale with `max-width: 100%`.

Exercise 8: Final Build

  1. Build one complete webpage using semantic HTML.
  2. Include navigation, image, table, and form.
  3. Apply responsive CSS styling.
