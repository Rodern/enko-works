How to justify a choice

  1. State the context (data size, sorted or not, time limit).
  2. Apply criteria (speed, simplicity, memory, maintainability).
  3. Conclude with evidence (estimated checks, constraints, trade-offs).

Practice

  1. A class register is unsorted and changes daily. Which search method is more suitable and why?
  2. An exam system has one million sorted candidate numbers. Which method is better and why?
  3. Give one situation where the faster algorithm is not automatically the best.
Answer guide: unsorted changing lists suit linear search; huge sorted lists suit binary search; faster can lose if complexity, maintenance, or data preparation costs are too high for the context.
