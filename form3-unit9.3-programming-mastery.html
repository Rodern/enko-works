Create Algorithms Using Flowcharts and Pseudocode

Learners must move fluently between visual (flowcharts) and structured text (pseudocode) algorithm design, then implement both in Python.

Memorize — flowchart symbols

  • Rounded rectangle → Start / Stop
  • Rectangle → Process / calculation
  • Parallelogram → Input / Output

Understand

Pseudocode has no fixed rules but uses consistent structure: one action per line, indentation for blocks. Flowcharts are visual; pseudocode is faster to write. Both describe the same logic. Python then runs that logic.

9CT.04

Use Predefined Sub-routines (Functions) in Algorithms and Python

Memorize

  • A sub-routine is a named reusable block of steps.
  • You call it by writing its identifier followed by ().
  • After it runs, control returns to the next line in the caller.
  • In Python, sub-routines are written with def.

Understand — why use sub-routines?

  • Reuse: write once, call many times.
  • Readability: main algorithm stays short and clear.
  • Maintenance: fix logic in one place only.
  • Testing: test each sub-routine independently.
SUBROUTINE addition()
  INPUT firstNumber
  INPUT secondNumber
  result ← firstNumber + secondNumber
  OUTPUT result
ENDSUBROUTINE

Demonstrate

Write pseudocode for a main program that asks which operation (add, subtract, multiply) and calls the matching sub-routine.

Practice

  1. Explain three benefits of sub-routines in a program.
  2. Identify one problem caused by a badly named sub-routine.
  3. Write a sub-routine to convert metres to centimetres.
  4. Show a main algorithm that calls it three times.

Python: Functions with def

Pseudocode
SUBROUTINE addition()
  firstNumber ← INPUT("First number")
  secondNumber ← INPUT("Second number")
  result ← firstNumber + secondNumber
  OUTPUT result
ENDSUBROUTINE

answer ← INPUT("Add? (yes/no)")
IF answer = "yes" THEN
  CALL addition()
ELSE
  OUTPUT "Exiting"
ENDIF
Python
def addition():
    first = int(input("First number: "))
    second = int(input("Second number: "))
    result = first + second
    print(first, "+", second, "=", result)

answer = input("Add two numbers? (yes/no): ")
if answer == "yes":
    addition()
else:
    print("Program exiting")

Count-Controlled Iteration — Flowcharts, Pseudocode, and Python for Loops

Memorize

  • Iteration = repeating instructions.
  • Count-controlled = repeats an exact known number of times.
  • Needs: counter variable, start value, stop value.
  • Python: for x in range(start, stop):
  • Stop value is excluded — use stop+1 to include it.

Understand

The loop below runs exactly 100 times. range(1, 101) gives 1, 2, 3 … 100.

for x in range(1, 101):
    print(x)

With a step: range(0, 51, 5) gives 0, 5, 10 … 50.

String Manipulation — Length, Uppercase, Lowercase in Python

Memorize — Python string methods

  • Length: len(string)
  • Uppercase: string.upper()
  • Lowercase: string.lower()
  • These return a new string — store the result to keep it.

Understand — why string manipulation?

  • Validate a password is long enough.
  • Normalize input so "YES", "Yes", "yes" all match.

  • Compare strings reliably without case issues.

9CT.09

Combine Sequence, Selection, Iteration, and Sub-routines in Full Programs

Mastery means selecting the correct construct for each part of a real problem and integrating all four constructs smoothly.

Memorize — the four constructs

  • Sequence: steps run in order, once.
  • Selection: if/elif/else — choose a path.
  • Iteration: for loop — repeat a set number of times.
  • Sub-routine: def — reusable named block.

Understand — all four together

total = 0                         # sequence
for i in range(0, 5):            # iteration
    mark = int(input("Mark: "))
    total = total + mark
    if mark < 50:                 # selection
        print("Needs improvement")
average = total / 5              # sequence
print("Average:", average)

Adding a sub-routine makes feedback reusable:

def feedback(mark):               # sub-routine
    if mark >= 70:
        print("Excellent")
    elif mark >= 50:
        print("Satisfactory")
    else:
        print("Needs improvement")

Demonstrate

Design pseudocode then Python for: process 10 products — input name and price, apply 10% discount if price > 100, output each final price and the overall total.

Practice

  1. Label each line in your algorithm: Seq / Sel / Iter / Sub.
  2. Refactor the discount calculation into a function.
  3. Create a full trace table for one run (3 items).
  4. Write three test cases: normal, boundary, invalid input.

Python: Full combined program

Pseudocode — all four constructs
SUBROUTINE apply_discount(price)
  IF price > 100 THEN
    price ← price * 0.90
  ENDIF
  RETURN price
ENDSUBROUTINE

grand_total ← 0
FOR i = 1 TO 10
  name ← INPUT("Product name")
  price ← INPUT("Price")
  final ← CALL apply_discount(price)
  OUTPUT name + " costs " + final
  grand_total ← grand_total + final
NEXT i
OUTPUT "Grand total: " + grand_total
Python
def apply_discount(price):         # sub-routine
    if price > 100:                # selection
        price = price * 0.90
    return price

grand_total = 0                    # sequence
for i in range(1, 11):             # iteration
    name = input("Product name: ")
    price = float(input("Price: "))
    final = apply_discount(price)
    print(name, "costs", round(final, 2))
    grand_total = grand_total + final

print("Grand total:", round(grand_total, 2))

9CS.04

Compilers and Interpreters — How Python Code Runs

Memorize

  • Computers only understand binary (0s and 1s).
  • Translators convert high-level code to machine code.
  • Two types: compiler and interpreter.
  • Python IDLE is an interpreter.
  • A compiler produces an executable (.exe) file.

Understand

When you run Python code, the Python interpreter reads and executes one line at a time. If it finds a syntax error, it stops — but lines before it have already run.

A compiler reads every line first, reports all errors at once, then creates a finished executable.

Demonstrate

Explain why Python is described as an interpreted language. Give one benefit and one limitation compared to a compiled language.

Practice

  1. Describe what happens when Python runs a program with an error on line 5 (after correct lines 1–4).
  2. Explain why a compiled program can run without the original compiler installed.
  3. Give one real-world use case that suits a compiled language.
  4. Give one school situation that suits an interpreter.

How Python runs on your computer

When you install Python and use IDLE, you are using the Python interpreter. It reads your .py file and translates each statement to machine instructions right as it runs them.
Important: Python programs stop when an error is found. Lines that ran before the error have already had their effect.
