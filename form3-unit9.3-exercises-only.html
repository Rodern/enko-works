9CT.09

Programming — Combined Constructs (Sequence + Selection + Iteration + Functions)

Programs to write

  1. School canteen: input 5 meal prices, apply 50% student discount, output individual and total cost. Use a function for the discount.
  2. Build a student grade book: input 5 student names and 3 marks each, calculate average per student, print pass/fail (≥50).
  3. Write a function grade(avg) returning "A", "B", "C", or "Fail". Extend the grade book to use it and add a count of students who passed.
  4. Process 10 products: input name and price, apply 10% discount if price > 100, output each final price and overall total.
  5. Input 10 names into a list, print each in uppercase, then print the longest name.
  6. Text-based quiz: 5 questions in a list; keep score; display final percentage and grade.

Core Programming Tasks

Tasks 1–6

  1. School canteen: input 5 meal prices, apply 50% student discount, output individual and total cost. Use a function for the discount.
  2. Input 10 names into a list, print each in uppercase, then print the longest name.
  3. Temperature log: input 7 daily temperatures, find the hottest and coldest, output the difference.
  4. Ask for a password; keep asking until it is at least 8 characters. (Extension: also check it contains a digit.)
  5. Write is_even(n) that returns True or False. Use it to print all even numbers from a list.
  6. Store student names and marks in two parallel lists. Print each name with a letter grade using grade().

Challenge Tasks 7–12

  1. Full grade book: 5 students, 3 subjects each, calculate average per student, class average, count of passes.
  2. Text-based quiz: 5 questions in a list; keep score; display final percentage and grade.
  3. Build a shopping cart: input item names and prices, apply discounts, show invoice with total.
  4. Input data for 10 people: name, age, salary. Calculate average salary and count how many are over 25.
  5. Write a simple encryption program that shifts each letter by 1 position (a→b, b→c, etc.).
  6. Build a simple number guessing game that generates a random number and lets the user guess.
