9CT.01

Follow, understand, edit and correct algorithms presented as pseudocode

inputs outputs variables selection debugging

Memorize

  • Find the inputs, process, and output.
  • A variable stores a value.
  • if / elseif / else is used for decisions.
  • Correct algorithms by changing only the step that is wrong.

Understand

When reading pseudocode, ask:

  1. What is the user asked to enter?
  2. What calculation or decision is made?
  3. What result is shown?
  4. Does the algorithm match the problem exactly?
Common correction types: changing an operator, changing a condition, adding an output, or changing the whole purpose of the algorithm.

Demonstrate

Edit this algorithm so it multiplies the two numbers instead of adding them:

number1 = input("Enter a number")
number2 = input("Enter a number")
result = number1 + number2
print(result)
number1 = input("Enter a number")
number2 = input("Enter a number")
result = number1 * number2
print(result)

Practice

  • Change an algorithm so it says: Hello Sam, you are 14 years old.
  • Fix a condition so Valid is shown only when the number is greater than 0.
  • Rewrite an algorithm so input directions change x and y.
9CT.02

Follow flowchart or pseudocode algorithms that use loops

for loop counter start value end value

Memorize

  • A loop repeats code.
  • A count-controlled loop runs a set number of times.
  • A for count in range(start, end) loop uses a counter variable.
  • In flowcharts, the counter must be declared, checked, and incremented.

Understand

To follow a loop correctly, track these four things:

  1. The counter name
  2. The start value
  3. The end/check condition
  4. The increment each time through the loop
for count in range(0, 10):
  print(count)

This prints numbers from 0 to 9.

Demonstrate

What does this output?

for count in range(0, 5):
  print(count + 1)

It prints:

1
2
3
4
5

The loop values are 0, 1, 2, 3, 4, but the program outputs each value plus 1.

Practice

  • Write a loop that outputs the 5 times table.
  • Write a loop that asks for 10 numbers and adds them together.
  • Sketch the flowchart steps for a counter that goes from 1 to 20.
9CT.07

Predict the outcome of algorithms that use iteration

trace table prediction loop output

Memorize

  • Predict first, then test.
  • Use a trace table to track changing values.
  • Focus on what is printed on each loop cycle.
  • Check whether the variable in the output is the same one used in the loop.

Understand

Strong prediction means you can explain why each line is printed. Do not guess. Walk through the loop line by line.

CounterCalculationOutput
00 + 22
11 + 23
22 + 24

Demonstrate

Predict the output:

total = 0
for count in range(1, 4):
  total = total + count
  print(total)
1
3
6

Explanation: total becomes 1, then 3, then 6.

Practice

  • Predict the output of a loop from 5 to 9.
  • Explain what changes if the start value changes from 0 to 1.
  • Create your own loop and ask a partner to predict the result.
9CT.08

Compare and contrast algorithms for the same task

requirements accuracy efficiency variables

Memorize

  • First ask: Does the algorithm meet the task?
  • Then compare number of lines and number of variables used.
  • Less code can mean a smaller file and less memory use.

Understand

At this stage, the most important test is whether the algorithm gives the correct result. If both work, choose the one that is clearer and more efficient.

Do not call a program “better” if it does not actually solve the problem correctly.

Demonstrate

Which algorithm is correct for Celsius to Fahrenheit?

Algorithm A:
Fahrenheit = Temperature + 32 * 1.8

Algorithm B:
Fahrenheit = Temperature * 1.8 + 32

Algorithm B is correct because the temperature must be multiplied by 1.8 first, then 32 is added.

Practice

  • Compare two ways to add 3 numbers together.
  • Circle the algorithm that uses fewer variables.
  • Explain why an incorrect result means the algorithm is not suited to the task.
9CS.06

Know how to convert between storage units

bit byte KB-MB-GB-TB conversion

Memorize

  • 1 byte = 8 bits
  • 1 nibble = 4 bits
  • To go to a larger unit, divide.
  • To go to a smaller unit, multiply.

Understand

Storage units are used because bits alone are too small for real computer memory and storage sizes.

Convert 5 MB into KB.

5 × 1024 = 5120 KB

Convert 8192 bytes into KB.

9CS.07

Know how to draw logic circuits for Boolean expressions

AND OR NOT truth table

Memorize

  • AND = both inputs must be 1.
  • OR = at least one input must be 1.
  • NOT = flips the input.
ABA AND BA OR B
0000
0101
1001
1111

Understand

To draw a logic circuit from an expression:

  1. Write the Boolean expression clearly.
  2. Identify the inputs (A, B, C...).
  3. Draw the first gate that must happen.
  4. Connect the output of one gate into the next gate if needed.

Example: (A AND B) OR NOT C

Demonstrate

What happens to the output of NOT A when A = 1?

NOT 1 = 0. The NOT gate flips the value.

For A AND B, what is the output when A = 1 and B = 0?

0, because both inputs must be 1 for AND.

Practice

  • Draw a circuit for A AND B.
  • Draw a circuit for A OR (NOT B).
  • Make a truth table before deciding the final output.
9CS.05

Describe how analogue sound is digitised

analogue digital sampling bit depth

Memorize

  • Analogue data is continuous.
  • Digital data is stored as binary.
  • Sampling measures the sound wave at regular intervals.
  • Bit depth affects how many possible values each sample can have.

Understand

Digitising sound usually follows this order:

  1. A microphone captures the analogue sound wave.
  2. The wave is sampled many times per second.
  3. Each sample is rounded to the nearest available value (quantisation).
  4. The values are encoded into binary and stored.
Higher sample rate and higher bit depth normally mean better sound quality, but also a larger file size.

Demonstrate

Why does a higher sample rate usually improve sound quality?

Because the system captures the sound wave more often, so the digital version is closer to the original analogue sound.

Practice

  • Explain the difference between analogue and digital sound in one sentence each.
  • Put these words in order: binary, sampling, microphone, stored file.
  • Explain why better quality sound usually needs more storage.
9CT.05

Describe and use binary searches

sorted list middle value halve the search

Memorize

  • A binary search only works on a sorted list.
  • Check the middle item first.
  • If the target is smaller, search the left half.
  • If the target is larger, search the right half.

Understand

Binary search is efficient because it removes half of the remaining items each step.

Sorted list: 3, 6, 9, 12, 15, 18, 21
Find 15:
1. Check middle = 12
2. 15 is bigger, so ignore the left half
3. Check middle of the right half = 18
4. 15 is smaller, so move left
5. Find 15

Demonstrate

Can you use a binary search on this list?

12, 4, 19, 7, 25, 10

No. The list is not sorted, so a binary search would not work correctly.

Practice

  • Sort a list of 8 numbers, then search for one number using the middle each time.
  • Explain why binary search is usually faster than checking one item at a time.
  • Describe the first three steps of a binary search in your own words.
